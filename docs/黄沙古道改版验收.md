# 黄沙古道改版验收

2026-11-04，依据用户提供的三张《万妖图录卷》截图及64秒视频进行了画面和玩法改版。视频按15秒间隔抽查备战、取牌及战斗画面；未从参考文件提取美术作为成品资产。城门、远山、树与沙地采用自绘SVG及CSS。

## 已实现

- 竖屏黄沙古道、城门背景、米白纸牌、书法字体回退与星级；五乘五棋盘、左侧异兽槽、底部暂存格及叠层牌墙。
- 首列开放五格；四层60张牌，按上层牌实际矩形遮挡判定是否可取。打乱保留牌型和空位，刷新整墙。
- 三张同字占三个独立槽，三合一后上阵。自动或点击手动合成；棋盘满则保留原牌。暂存槽可付灵玉扩展至七格。
- 六条字系：金鍂鑫、木林森、水冰淼、火炎焱、土圭垚、日昍晶。棋盘两张同阶同字升阶。
- 支持拖动，也支持触屏先点单位再点目标合并或移动。撤回的已合成字可直接重新上阵。
- 备战与战斗分离，出战隐藏卡池和工具；外围行军、人皇生命、妖怪血条、射线与伤害飘字、波次进度、一倍和二倍速。
- 三点生命、十二波递进。此数值为项目自己的初始平衡值，并未声称与原版数值一致。
- 无单位时不能出战；战斗中禁止取牌或消费。铲子无格可开不扣费。击杀或漏怪及时清除怪物节点。
- 本地结算可直接再战；再战清零灵玉、异兽、槽位和统计，不重复发放答题奖励。主动选择结算后才回传战报。
- 主项目提供“免答题试玩新场景”，零灵玉、无需调用模型、不生成学习成绩；正式答题奖励入口仍保留。

## 后续规则修订

以下取代前文“固定首列”和“槽内激活”的旧说明：开局为靠边随机连通五格；每副牌随机生成0至2个不同神兽残字。槽、棋盘或激活神兽中已使用的残字不会再生成。点击优先进入神兽槽；槽满则进入空棋盘，两处都满时原牌不消耗。只有棋盘上同一行相邻、从左到右的青龙或白虎会原位激活。反序、竖排、跨行、混搭以及仅在神兽槽凑齐均不激活。残字激活前不攻击、不提供增益。

铲子可拖到指定封锁格，也可先点铲子再点目标。牌堆铲子成功解锁才消耗牌，商店铲子成功解锁才扣费。拖到已亮格、无效目标或战斗中拖动均不消费。触屏支持指针拖动和点选替代操作。

最新验证：98项Python测试与106项游戏DOM交互断言通过。采样80次随机开局验证靠边、五格和四邻接连通；采样150副牌验证0至2个与不重复；重复刷新验证不再生成已持有或激活残字。拖放通过真实dragstart/drop事件验证，并补充触屏pointerdown/pointerup路径测试。


## 四星与闯关交互修订

- 水系二星由冰纠正为沝。六条普通字系全部支持四星，用四个基础字在四角排布，不依赖稀有四叠字字体。
- 备战和闯关均支持棋盘字拖动及点选移动。空位移动，异字或不同阶字交换，同阶同字融合；四星封顶。交换保留各字攻击冷却。
- 神兽两半都有独立拖动落点，拖走任一字可拆解并与目标文字交换；也可点“拆”在原地还原两个字。明确拆解后不会立即自动原地重组，移动重排后可重新激活。
- 拆解及时移除增益与占位；重新组成神兽保留本局星级，重开清空进度，不重复叠加神兽增益。
- 三星、四星普通字拖到神兽任一半进行吞噬。按旧交接约定默认55%概率升星、神兽最高五星；失败消耗但不降星，满星不消耗。低星字按正常交换规则拆开神兽，不作为吞噬材料。
- 此轮98项Python测试和136项游戏DOM断言通过。新增测试涵盖四星外观结构、闯关移动交换融合、左右半拆解、重组保星、吞噬成功失败和满星边界。
- 浏览器使用明确标注的开发验收场景核查四星排布，并实际操作验证battle阶段水与沝交换。该场景预置单位仅供渲染检查，不是正式试玩进度；正式试玩仍从随机开局和零灵玉开始。
