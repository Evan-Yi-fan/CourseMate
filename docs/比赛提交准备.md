## 可直接填写的作品基本信息

作品名称：CourseMate 课友

建议主题：科研与知识挖掘

作品简介：CourseMate 课友面向课程资料分散、问答缺少出处、练习准备费时的学习场景，将用户上传的 PDF、DOCX、TXT、PPTX 和 PPT 资料转为按课程组织的知识库。系统支持带文件名及页码引用的问答、资料不足时拒答、课程试题生成、程序自动判分和错题分析。独立小游戏“灵玉秘境”把答题获得的灵玉用于五行卡牌合成与布阵，提供练习后的互动反馈。应用与学习记录保存在本机，模型调用使用用户配置的服务。

技术亮点：本地中文向量检索；按课程隔离；检索阈值与模型话术两段拒答；结构化试题校验；Python确定性判分和奖励；独立无CDN游戏前端。

限制说明：不支持扫描PDF的OCR；单用户本地应用；真实模型调用需要有效密钥；游戏会因Streamlit页面重跑而重置，战绩尚未持久化；没有吞噬升星功能。

## 三分钟演示脚本

| 时间 | 实际画面 | 讲解要点 |
|---|---|---|
| 0:00–0:20 | 首页课程列表 | 课程讲义多，问答缺出处、练习费时；介绍一个连续学习流程 |
| 0:20–0:45 | 上传自建样例资料并显示入库状态 | 课程隔离，支持三种文件格式；演示前确认本地模型已缓存 |
| 0:45–1:25 | 正常问答并展开引用，再问资料外问题 | 引用对应文件与页码；资料没有依据时拒答；只讲实际输出 |
| 1:25–1:55 | 生成少量试题并提交 | 题目基于资料生成，判分由Python完成；至少答错一题以便展示分析 |
| 1:55–2:25 | 展示游戏答题奖励与布阵 | 点卡、三合一、出战；不等待打完三波，不宣称未实现机制 |
| 2:25–2:50 | 学习分析页 | 用真实作答记录展示正确率、错题及复习建议 |
| 2:50–3:00 | 回首页总结 | 资料→有据问答→练习→错题复习；指出开源仓库和运行方式 |

建议先录真实操作再配音剪辑。控制在2分50秒左右，给片头片尾留余量。不可用伪造答案或测试桩冒充真实模型演示。
