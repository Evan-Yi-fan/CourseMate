## 4. 发现并修复的问题

### 4.1 评分漏洞（严重，已修）

**现象**：普通答题模式下，未作答的题完全不进入分母。若 2 道题只答对 1 道，
显示 `1/1 = 100 分`——"少答反而得分高"。

**修复**：
- 抽出纯函数 `modes/base.py::complete_answers()`，把未作答补成空串；
- 所有模式（含未来的游戏模式）复用同一函数；
- 结果区显式提示"有 N 道题未作答，已按答错计入总分"。

**验证**：真实题库 2 题只答 1 题 → `得分 50 / 答对 1/2`，并出现未作答提示。

### 4.2 重复上传产生重复向量（合规缺口，已修）

任务书 §5.3 要求"重复上传同一文档时应删除旧向量后重建"。原实现做到了
"同一 document_id 重建"，但同名文件再次上传会新建一条记录 → 两份向量。

**修复**：`handle_upload` 先按 `(course_id, filename)` 查找，命中则复用原记录并覆盖。
**验证**：真实库重复上传同一 PDF → `replaced=True`，文档数仍 2、向量块仍 6。

### 4.3 学习分析页缺异常兜底（已修）

`advice()` 只捕获 `LLMError`，其他异常会把堆栈直接抛给用户（违反 §11）。
已在页面层加 `try/except`，只显示异常类型。

### 4.4 模型启动联网校验（已修）

首次加载模型时会向 Hub 校验版本，网络抖动会重试并拖慢首屏（实测出现过 SSL 报错重试）。
新增 `EMBEDDING_OFFLINE` 开关，设 `true` 后只读本地缓存：**加载 7.5 秒、零联网**。
本机 `.env` 已设为 `true`，README 说明了换机器时如何回退。

### 4.5 未作答提示被 rerun 吞掉（已修）

原来在提交时 `st.warning` 后紧接 `st.rerun()`，提示来不及显示。改为在结果区渲染。
