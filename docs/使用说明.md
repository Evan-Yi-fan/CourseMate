# CourseMate 课友使用说明

[返回项目首页](../README.md)

## 课程与资料

首页创建课程只需填写名称，点击「设为当前课程」切换学习范围。上传、问答、出题和分析均围绕当前课程。

在「课程知识库」选择一个或多个文件，再点击「开始处理」。处理结束后，上传栏会清空，成功与失败原因会显示在页面上。成功的资料状态为「已入库」，失败资料可删除或重建索引。

| 格式 | 支持范围与要求 |
| --- | --- |
| PDF | 提取文字层，保留真实页序；不含 OCR，扫描图片无法直接提取。 |
| DOCX | 提取段落和表格；流式文档不保证与 Word 排版页码对应。 |
| TXT | 提取文本，适合补充说明和复习笔记。 |
| PPTX | 按幻灯片实际顺序提取文本框、表格、组合图形、常见图表内容及备注，不依赖 Office。 |
| PPT | 需要 Windows、本机可用的 PowerPoint 和 pywin32；在独立进程中只读转换为临时 PPTX 后解析，禁用宏，最多等待 60 秒。 |

单文件默认上限 **50 MB**，可通过 `.env` 的 `MAX_UPLOAD_MB` 调整。幻灯片空白页跳过入库，但后续引用页码不前移。图片内文字和复杂 SmartArt 不保证提取；建议补充文字讲义，或转换成带文字层的 PDF。

删除单份资料会清理文件与检索索引；既有题目、答题记录和聊天历史保留，因此历史内容可能仍包含旧资料片段。删除整门课程会清除该课程的文件、索引、题目、作答和聊天记录。两者均需在页面中勾选确认，成功后不能在页面撤销。

## 问答、练习与分析

问答前先确保资料已入库，模型配置可用。回答下方可以展开来源，检查文件名、页码、片段及被引用情况。提示卡片只填充输入框，仍需手动提交。

「Agent 自动路由」默认关闭。开启后，可输入「帮我出 3 道单选题」「看看我的错题和正确率」等请求，路由至对应工具。普通问答与 Agent 问答均不保证消除模型错误，应结合引用核对。

智能试题与游戏战前答题均支持 **1–10 题、单选或判断、课程资料必选多选与全选**。未选择资料时无法生成；出题仅使用所选已入库文件的片段，属于内容取样，不保证穷尽整份长课件。模型生成后须通过结构校验，判分由程序比对保存的答案完成。

学习分析基于当前课程已保存的作答，展示正确率、错题和知识点表现。AI 复习建议需要模型配置；没有作答时不会编造学习表现。

## 游戏操作

- 战前答题后进入游戏：初始 30 灵玉，答对每题增加 10 点；也可直接点击「免答题试玩新场景」。
- 只能取出没有被上层遮挡的牌。暂存格中的三张同字合一上阵，棋盘同阶同字两两融合，最高四星。
- 开局随机开放靠边连通的五格。铲子可直接拖到希望点亮的封锁格，也可先点铲子再点目标。
- 备战和闯关都能拖动棋盘字：空位移动、不同字交换、同阶同字融合。
- 每副牌随机包含 0–2 个不重复神兽残字，优先进入神兽槽。棋盘相邻格从左到右横排「青龙」或「白虎」才激活；反序、竖排、混搭均无效。
- 拖走神兽中的一个字即可拆解；把三星及以上普通字拖给神兽可吞噬升星，默认成功率 55%，神兽最高五星。
- 守卫十二波，人皇有三点生命；游戏内重开恢复 30 初始灵玉，不重复发答题奖励。

游戏嵌入 Streamlit iframe，操作外层页面控件可能导致本局重置。游戏进度没有持久化，答题记录会保存在学习数据中。

## 配置与常见问题

配置从根目录 `.env` 读取，已有系统环境变量优先。修改配置后，请停止服务并重新启动。

| 情况 | 处理方式 |
| --- | --- |
| 模型未配置 | 在 `.env` 填写 `LLM_API_KEY`、`LLM_BASE_URL`、`LLM_MODEL`。密钥不可提交到仓库。 |
| 模型名称无效或返回 404 | 以供应商账号实际可用模型列表为准，同时核对接口地址。 |
| 首次入库较慢 | 本地向量模型首次需要下载并加载；后续会复用缓存。安装 PyTorch 等依赖也需要时间和磁盘空间。 |
| 提示本地模型缓存不存在 | 首次运行设置 `EMBEDDING_OFFLINE=false`，完成下载后再启用离线缓存模式。 |
| 模型下载失败 | 检查网络；`.env.example` 提供可选 `HF_ENDPOINT` 镜像设置，也可配置支持 embeddings 的兼容服务。 |
| 使用 `hash` 向量后端 | 仅用于调试流程，检索质量不代表真实效果，不建议用作正式体验。 |
| 更换了向量模型 | 对既有资料逐份重建索引，避免新旧向量维度不一致。 |
| 旧版 PPT 转换失败 | 确认 Windows 本机 PowerPoint 可正常启动；或用 Office 另存为 PPTX。仅改扩展名无效。 |
| 查不到资料中的内容 | 检查入库状态、解析范围和引用片段；扫描件或图片文字可能需要补充可提取文本。 |
| 没有 API 密钥 | 可浏览首页、创建课程并免答题试玩游戏；完整 AI 问答、出题和复习建议需要密钥。 |

可使用环境自检辅助定位问题：

```powershell
# 不调用远端大模型
.\.venv\Scripts\python.exe scripts/check_env.py --skip-llm

# 包含一次大模型连通性检查，会使用你的模型服务
.\.venv\Scripts\python.exe scripts/check_env.py
```

安装使用根目录的 `requirements.txt`；`requirements/locked.txt` 记录已验证环境的完整依赖版本，便于核对环境差异。正常运行不需要 Node.js，游戏测试依赖集中在 `tests/game/`。

从项目根目录执行游戏测试：

```powershell
npm --prefix tests/game ci
npm --prefix tests/game test
```

Python 共用界面代码位于 `ui/common.py` 和 `ui/quiz.py`，游戏运行资源位于 `game/web/`，测试脚本与 Node 依赖清单位于 `tests/game/`；无需到子目录内启动主应用。

## 数据位置与隐私

默认数据保存在项目根目录的 `data/`：`coursemate.db` 保存学习记录，`chroma/` 保存向量索引，`uploads/` 保存上传文件。密钥存放在 `.env`。以上内容均已被 Git 忽略，公开仓库只保留配置示例和原创演示资料。

使用远端模型时，提问、检索片段、出题上下文或生成复习建议所需的错题信息会发送给用户配置的服务供应商。请仅上传自己有权使用且适合交给该服务处理的资料。

## 三分钟展示建议

| 时长 | 展示内容 |
| --- | --- |
| 0:00–0:20 | 首页与项目目标：资料分散、查证困难、练习准备耗时。 |
| 0:20–0:45 | 导入原创样例，展示入库状态。 |
| 0:45–1:25 | 一次带来源的问答，再展示资料不足时的提示。 |
| 1:25–1:55 | 选择资料生成少量题目，提交并展示判分与解析。 |
| 1:55–2:20 | 展示战前答题奖励、合成与布阵，不必等待打完十二波。 |
| 2:20–2:50 | 展示真实作答形成的错题、知识点表现与复习建议。 |
| 2:50–3:00 | 总结学习流程，展示仓库地址。 |

演示前预热向量模型并确认模型服务可用。封面和海报是展示设计图，不作为应用实际界面截图；演示视频应录制真实操作和输出。
