# 在线体验部署

当前体验地址：[CourseMate 课友](https://coursemate-nzozaoqbsnvfadv8u6hyjq.streamlit.app/)。

公开展示入口是 `streamlit_demo.py`，本地完整版继续使用 `app.py`。

## 部署步骤

1. 使用 GitHub 登录 https://share.streamlit.io/ ，点击 Create app。
2. 仓库选 `Evan-Yi-fan/CourseMate`，分支 `main`，入口 **`streamlit_demo.py`**。
3. Advanced settings 选择 Python **3.11**，把 `.streamlit/secrets.example.toml` 内容粘贴到 Secrets，并填写有效的模型 ID 和密钥。
4. 点击 Deploy；首次安装依赖和下载中文向量模型可能需要较长时间。
5. 成功后复制平台实际生成的 `https://….streamlit.app` 地址，用无痕窗口验证问答、出题与游戏，再放入 README 和海报二维码。

## 公开版行为

- 自动导入原创数字图像处理 PDF 与补充讲义；保留真实语义检索和 AI 调用。
- 共享只读样例索引，每位访客有独立学习数据库，聊天、题目和作答记录不互相显示。
- 禁止访客创建/删除课程、上传/删除资料、重建索引及修改模型配置。直接访问模型设置页也会拦截。
- 模型配置只读部署平台环境变量/Secrets，忽略本地保存的模型配置文件，密钥不展示给访客。
- 单进程共享额度：滚动24小时200次、每分钟10次模型请求，失败和重试计数；单次输出最多3000 token。重启会重置额度，建议同时在供应商设置独立密钥及费用上限。
- 学习记录为临时体验数据，会话中断或重启后可能重置；不适合保存真实课程档案。示例课程可在每次启动自动恢复。
- 不收集访客上传文件，因此云端不提供旧版 `.ppt` 的 Windows PowerPoint 转换；本地完整版继续支持。

## 本地检查

```powershell
.\.venv\Scripts\python.exe -m streamlit run streamlit_demo.py
```

## 故障处理

- GitHub 登录500：刷新，或使用系统浏览器登录 GitHub 后重试，不需要修改项目代码。
- 模型下载失败：确认 Hugging Face 网络可用；首次启动不要设置 `EMBEDDING_OFFLINE=true`。
- 免费实例内存不足：应增加资源或配置可用的云端 embedding 接口，不能把 hash 测试向量作为正式检索效果。
- AI 提示未配置：核对 Secrets 顶层的 `LLM_API_KEY`、`LLM_MODEL` 和 `LLM_BASE_URL`，保存后重启。
