# 学习工作台 UI 优化记录

首页改为浅色学习工作台，深绿侧栏导航与米白卡片；本地SVG插图，不依赖外部素材。首页顺序为概览横幅、真实累计数据、当前课程与正确率、四个学习工具、游戏入口、课程集合与创建、折叠系统状态。

共享主题位于ui/theme.css，原生组件颜色位于.streamlit/config.toml。ui_common.boot拆为缓存配置初始化与每次页面渲染，避免样式与导航只在首轮出现。多页均复用同一侧栏及组件样式。首页不再为显示统计而初始化ChromaDB。

课程卡片可切换当前课程；pending_course_id在控件渲染前同步，避免旧选择器覆盖卡片选择。卡片中的用户输入在HTML输出前转义。课程创建、模型连通测试和真实学习数据入口保留；系统配置默认收起，模型“已配置”不冒充“已连通”。

验证：完整99项Python测试通过；最后手机布局修整后4项页面测试再次通过。新增跨页课程选择保持测试；游戏页面测试按Streamlit本地文档改为从主入口切页执行。浏览器检查桌面侧栏、卡片和快捷入口；390像素宽度无横向溢出，统计为2×2排列。没有为了视觉优化调用真实模型、生成或修改真实课程资料。

修改前app.py和ui_common.py保存在.handoff-work/ui-before，备份目录不随源码发布。
